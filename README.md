# Power UP 게임 🎮💰

클릭하여 부를 키우는 재미있는 웹 게임입니다!

## 🎯 게임 방법
1. 시간 제한을 선택하세요 (30초 ~ 3분)
2. "게임 시작" 버튼을 클릭하세요
3. "Power UP 🔥" 버튼을 5번 클릭하면 레벨이 올라갑니다
4. 총 50레벨까지 도전하세요!

## ✨ 특징
- 🎮 50단계의 레벨 시스템
- ⏰ 시간 제한 모드 (30초 ~ 3분)
- 🎉 화려한 레벨업 효과
- ✨ 파티클 애니메이션
- 📊 실시간 진행도 표시
- 🎊 10레벨 달성마다 특별 이펙트
- 🎆 게임 종료 시 폭죽 효과
- 🔊 효과음 (레벨업, 클릭, 달성, 게임 종료)
- 🌈 레벨별 테두리 색상 변경
- 📱 모바일 반응형 디자인

## 🎨 기술 스택
- HTML5
- CSS3 (Animations, Gradients, Glassmorphism)
- JavaScript (Vanilla)
- Canvas API
- Web Audio API
- NanumHuman 폰트

## 🚀 로컬 실행
```bash
cd /Users/user/Desktop/부강화게임
python3 -m http.server 8080
```

그 후 브라우저에서 `http://localhost:8080` 접속

## 📦 배포
Vercel을 통해 배포되었습니다.

### Vercel 배포 방법
1. GitHub에 코드 푸시
2. Vercel 계정으로 로그인 (https://vercel.com)
3. 저장소 연결 및 배포

또는 Vercel CLI 사용:
```bash
npm install -g vercel
vercel --prod
```

## 🎮 게임 규칙
- 레벨 1-9: 기본 화이트 테두리
- 레벨 10-19: 오렌지 레드 테두리
- 레벨 20-29: 다크 오렌지 테두리
- 레벨 30-39: 골드 테두리
- 레벨 40-49: 라임 그린 테두리
- 레벨 50: 시안 테두리 (최고 레벨!)
